Microtoll identity demo

Creates, locks, restores and deletes an identity using only @microtoll/crypto-core and @microtoll/identity. The "server" is the package's in-process stand-in running in this page (until blind-store exists); reload the page and it forgets everything, while the trusted-device session and the device record survive in this browser's storage.
