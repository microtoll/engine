Microtoll notes

End-to-end-encrypted notes with sharing and revocation, on the blind-store reference server. The server holds sealed blobs, hashed capabilities and the shelf each note is filed on; it cannot read a note, say who owns one, or tell which notes on a shelf are yours. Read notes.js for the whole model, and the README for what the server does learn.
